# 三星计算器

为个人使用制作的离线计算器，原创代码，无广告、账号和付费功能。计算、设置、存档、回收站只保存在本机。本项目与三星电子没有官方关联。

## 功能

- 竖屏流水账式计算；四则运算、退格、清除输入、精确小数与小数位数设置。清空后可直接输入负号，例如 `−8÷−2=4`，四则运算键不会自动带入上一笔结果。百分比按 iPhone 基础计算器习惯处理：`200+10%=220`、`200−15%=170`，乘除仍按百分数本身计算，例如 `500×7%=35`。
- 记录显示在键盘上方，打开 App、进入历史页或新增记录后自动定位到最新一行。点按主界面计算行会弹出圆角毛玻璃菜单，可插入备注、分段求和、求和、复制答案或整行、删除和清空；备注以类似日期的浅灰色显示在对应算式左侧，旧备注也会按同样方式显示。长备注只在记录行显示预览，点按备注或菜单里的“查看备注”可以看到全文并复制。历史页点按结果可继续计算。浅色系统使用偏白玻璃，深色系统使用深灰玻璃，清除历史的确认框也保持同样样式。
- 每条计算记录可单独标注半透明背景色，并叠加表情或图片小标记。颜色可从内置圆角调色盘选择，也可从相册／文件里的图片提取；自选色自动保存到“我的颜色”，可在其他记录重复使用。图片本身也能作小标记。底色和小标记可分别清除，会在计算流水与历史页显示，并随记录保存、存档和恢复。已有备注可在记录菜单或全文弹窗中修改，多条备注可分别编辑；编辑时留空保存会删除该条备注。
- 删除单条或清空历史会把完整记录移到回收站，包括备注、底色及表情／图片；恢复最近一次会恢复那次删除的全部记录，恢复全部会保留每批记录的顺序。永久清空回收站需连续确认三次。
- 所有主题使用同一套三星式圆形键盘布局，可选三星经典、三星墨黑、清晨薄荷、冰川蓝、落日橙、樱花粉、极光紫、石墨灰和暮光橙。除固定墨黑外，颜色会跟随 iPhone 系统的浅色／深色模式切换。键盘按压时有缩放和颜色反馈，长按不会选中网页文字。
- 从右上角尺子图标打开独立单位换算页，支持长度、重量、面积、体积、温度、速度、时间和数据单位；实时显示结果，点按结果复制，不把换算写进计算流水。
- 长输入自动向左滚动，计算行可换行，结果使用大整数与精确小数运算。
- 普通话按键播报和中文结果报数，例如“等于十万五千六百二十一”。默认声音使用用户提供的计算器音频剪辑，在本机按中文数位顺序播放；未收录的词使用 iPhone 离线语音补足。声音页点选时试听“一二三等于六”，物理计算器选项会播放收录的按键录音；另有静音、男声、女声、系统默认声音和点击声选项。男/女声优先使用手机已安装的对应音色；系统缺少该音色时，会用不同音调和语速区分。三星主题短按 `C` 清除输入，长按 `C` 开关声音。
- 原创绘制的高清计算器图标；触感、字体、经典／紧凑键盘、小数位数、千分位、日期和“万”标记。设置项会同步作用于当前主题。
- iOS 原生容器内置网页资源，不需要联网；同时支持通过 HTTPS 安装为主屏幕网页应用。

## 本地预览

```bash
node build.mjs
python3 -m http.server 8765 --directory Web
```

打开 `http://localhost:8765`。测试：`node --test tests/*.test.mjs`。

## 安装到 iPhone

1. 安装与当前 macOS 兼容的 Xcode，并在 Xcode 设置中登录自己的 Apple ID。当前 Mac 为 macOS 26.4；App Store 最新版要求 26.6，可从 [Apple Developer Downloads](https://developer.apple.com/download/all/) 获取 Xcode 26.4.1。
2. 打开 `iOS/XiaoMingCalc.xcodeproj`，选中项目的 `XiaoMingCalc` target，在 Signing & Capabilities 选择自己的 Personal Team。
3. 用数据线连接 iPhone，手机点“信任”，必要时开启开发者模式。
4. 在 Xcode 顶部选择自己的 iPhone，按 Run。首次启动若有提示，按 iPhone 系统提示信任开发者。

本工程没有第三方 SDK 或外部运行依赖。Apple 免费个人签名配置文件有效期为 7 天。用 Xcode 直接安装时，需要定期重新编译并覆盖安装；不要卸载原 App，以保留本机数据。

当前手机使用 Xcode 免费签名安装。续签时保持相同 Apple 账户、Team 和 Bundle ID，在 Xcode 中选择同一部 iPhone 再按 Run，即可覆盖安装；不需要先删除 App。更换签名方式前请先用“复制全部”备份重要记录。

## 音效素材

`Web/sounds/` 中的普通话计算器音效由项目使用者从网络收集的音频片段制作。原始素材的具体出处与授权范围尚未核实；公开本仓库并不代表这些音效获得开源许可。需要再分发或商用音效时，请先确认原素材的许可，或替换为自己有权使用的录音。

仓库只保存源码与开发资源，不上传个人签名、手机数据或 IPA 安装包。

## SideStore 续签方案

`./build-ipa.sh` 可在安装 Xcode 后生成未签名的 IPA。将它从 SideStore 导入并由 SideStore 用自己的 Apple 账户签名安装后，可使用 SideStore 的刷新功能续签；它会尝试在后台刷新，但不保证每次自动成功。需留意剩余天数，必要时手动刷新。首次安装 SideStore 需要按其[官方安装说明](https://docs.sidestore.io/docs/installation/install)完成配对和 LocalDevVPN 设置。不要把 Apple 账户凭据或配对文件传给本项目。

## 隐私与备份

删除 App、清理其网站数据或更换手机可能删除本机流水。存档仅在 App 内保存；重要记录可用“复制全部”粘贴到备忘录备份。
